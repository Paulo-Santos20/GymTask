# frontend/src/exercise-names/

## Responsibility

Per-language display names for the built-in exercise catalogue. One file per language,
currently only `pt-BR.js`.

- Structure: flat JSON map `{"<exId>": "<translated name>"}` keyed by numeric ExerciseDB
  id, serialized as `export default {…}` on a single line
  (`"1000": "elevação de panturrilha invertida unilateral com faixa elástica"`, …).
- Generated — do not hand-edit: header says
  `generated by scripts/build-pt-br-exercise-names.mjs — edit scripts/exercise-name-sources/pt-BR.json`.
  Source of truth: `scripts/exercise-name-sources/pt-BR.json`.

## Design

- **Generated, complete**: unlike `instr/`, coverage must be 100% — the build script throws
  if any `EXDB` id is missing, unknown, or an empty string, then writes entries in `EXDB`
  order. Translation pipeline: `scripts/translate-pt-br-exercise-names.mjs`.
- **Bilingual rendering**: `exerciseNameFor(ex)` (`i18n-core.js:36`) returns
  `"<pt-BR> (<English>)"` — the English original in parentheses — unless the translated
  name equals it case-insensitively (loanwords like "Burpee"), in which case just the
  translation. User-created exercises have no pack entry and keep their exact name.
- **Search is bilingual**: `exerciseNameSearchText(ex)` returns
  `"translated EnglishName"` (i18n-core.js:50) so search matches either language.
- Language gating via `EXERCISE_NAME_LANGS = ['pt-BR']` (i18n-core.js:11).

## Flow

1. Translate: `scripts/exercise-name-sources/pt-BR.json`.
2. Build: `node scripts/build-pt-br-exercise-names.mjs` → rewrites
   `exercise-names/pt-BR.js` (validates ids, completeness, non-empty strings).
3. Runtime: `setLang` (lib/i18n.js) resolves `../exercise-names/<lang>.js` via
   `import.meta.glob('../exercise-names/*.js')` when `EXERCISE_NAME_LANGS` includes the
   lang → `_setLangState` stores it as `exerciseNames`.
4. Read: `exerciseNameFor` / `exerciseNameSearchText` fall back to `ex.n` (English
   catalogue name) when the pack or id is absent.

## Integration

- Loaded in the same `setLang` call as `../locales/*.js` and `../instr/*.js`.
- Display consumers (via `lib/i18n.js`): `sheets.jsx` (exercise sheets, lists, add-to-routine),
  `views/Library.jsx`, `views/Workout.jsx`, `views/RoutineEdit.jsx`, `views/Stats.jsx`,
  `components/MuscleExplorer.jsx`, `components/Media.jsx` (img alt), `lib/plan-share.js`,
  `lib/strength-exercises.js`.
- Search consumer: `lib/exercises.js:223` — `normalizeStr(exerciseNameSearchText(e))`
  builds the search index; `getVersion()` in its deps invalidates the cache when the
  language pack changes.
- Guard test: `lib/pt-br-exercise-names.test.js` (translated vs. fallback, search text,
  user-created exercise names untouched).
- Add a language: add `scripts/exercise-name-sources/<lang>.json`, generate the pack,
  add the code to `EXERCISE_NAME_LANGS`.
