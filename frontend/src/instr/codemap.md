# frontend/src/instr/

## Responsibility

Per-language exercise instruction text: how-to steps shown in the "How to" section of
exercise sheets. One file per language, currently only `pt-BR.js`.

- Structure: flat JSON map `{"<exId>": ["step 1", "step 2", …]}` keyed by the numeric
  ExerciseDB id (`"1000"`, `"1001"`, …), serialized as `export default {…}` on a single line.
- Generated — do not hand-edit: header says
  `generated by scripts/build-pt-br-instructions.mjs — edit scripts/instruction-sources/pt-BR.json`.
  The editable source of truth is `scripts/instruction-sources/pt-BR.json`.

## Design

- **Generated, validated output**: `scripts/build-pt-br-instructions.mjs` loads `EXDB`
  from `lib/exercises-data.js` and fails the build if an id is unknown, step count differs
  from `ex.st.length`, a step is empty, or a step is still byte-identical to the English
  source. Output is re-ordered to match `EXDB` order.
- **Partial coverage is legal**: only translated ids appear in the pack; missing ids fall
  back at read time (`instrFor` returns `ex.st`, the catalogue's English steps).
- **Language gating**: packs are only active for `INSTR_LANGS = ['pt-BR']`
  (`i18n-core.js:10`); other languages get `instr = null` → English fallback, and the UI
  shows an "instructions in English" hint (`sheets.jsx:698`).

## Flow

1. Translate: `scripts/instruction-sources/pt-BR.json` (via `translate-pt-br-stage.mjs`).
2. Build: `node scripts/build-pt-br-instructions.mjs` → rewrites `instr/pt-BR.js`.
3. Runtime: `setLang` (lib/i18n.js) resolves `../instr/<lang>.js` through
   `import.meta.glob('../instr/*.js')` only when `INSTR_LANGS.includes(l)`, and hands the
   map to `_setLangState`, which stores it as `instr`.
4. Read: `instrFor(ex)` = `(instr && instr[ex.id]) || ex.st || []`
   (`i18n-core.js:32`).

## Integration

- Loaded in the same `setLang` call as `../locales/*.js` and `../exercise-names/*.js`.
- Primary consumer: `sheets.jsx` — `instrFor(ex).map(...)` renders the `<ol class="steps-list">`
  in the exercise detail sheet (line 698), guarded by `INSTR_LANGS.includes(getLang())`.
- Exported from `lib/i18n.js` (`instrFor`, `INSTR_LANGS`); core logic lives in
  `lib/i18n-core.js` (Node-loadable, tested without a browser).
- Guard test: `lib/pt-br-instructions.test.js` imports the pack and checks coverage /
  structure against `EXDB`.
- Add a language: create `scripts/instruction-sources/<lang>.json`, run the build with
  the lang swapped in, add code to `INSTR_LANGS`.
